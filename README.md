# Portfolio

My personal site — hand-written HTML, CSS and JavaScript. No framework, no build
step, no bundler. Served from GitHub Pages.

**Live:** https://gnm7208.github.io/Portfolio/

## Layout

```
index.html        the site — one self-contained file, styles inline
assets/img/       portrait and favicon
redesign/         alternative designs, viewable on Pages before adopting one
```

To adopt a redesign, copy it over the live page:

```sh
cp redesign/b-daylight.html index.html
```

Each redesign is also browsable directly, e.g.
`https://gnm7208.github.io/Portfolio/redesign/c-ledger.html`.

| File | Direction |
|---|---|
| `redesign/00-original.html` | the page as it was before the redesigns |
| `redesign/a-console.html` | dark terminal identity, properly finished |
| `redesign/b-daylight.html` | light, phone-first, client-facing |
| `redesign/c-ledger.html` | art-directed around the ledger metaphor |
