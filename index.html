about_me

I started as a naive computer-science enthusiast who wanted to learn everything — code, Unix, Linux, theory — and I'm still that person, just with better error handling. I build projects from the ground up: planning, design, implementation, and deployment. My dream? To help carve out a name for Africa in software and robotics. (Blame the Transformers movies. I do.)

I trained in full-stack software development at Moringa School and in mobile development (Kotlin/Android) at eMobilis Technology Institute, both in Nairobi. My happy place is a Flask API talking to a PostgreSQL database, with a React frontend that doesn't need a single !important.
